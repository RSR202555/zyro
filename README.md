# Zyro - Plataforma Privada de Comunicação

Zyro é uma plataforma privada de comunicação em tempo real desenvolvida em Monorepo contendo Web (Next.js), Desktop (Electron) e Mobile (Expo/React Native).

## 🚀 Funcionalidades Principais
- **Comunidades e Canais**: Canais de texto e voz com suporte a realtime.
- **Canais de Voz Estilo Discord**: Conexão automática ao clicar, lista de membros aninhada na barra lateral e indicador de fala reluzente em tempo real.
- **Sistema de Convites**: Links diretos de convite (`/invite/[code]`) com botão de cópia instantânea e suporte a login/onboarding automático.
- **App Desktop Nativo**: Suporte a Electron com atalhos globais, minimização para a bandeja e suporte nativo a compartilhamento de tela.

## 🛠️ Como Executar
```bash
# Instalar dependências
npm install

# Rodar Web
npm run dev:web

# Compilar Desktop Executável (.exe)
npm run build:desktop
```
